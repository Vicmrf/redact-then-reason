        How this works
        
Regex + Luhn detectors (emails, phone numbers, SSNs, card numbers) always run instantly in this page. Then, if Gemini Nano is available in your browser, an on-device pass adds names, organizations and addresses. Nothing is sent anywhere.

        
Explain: on-device, Gemini Nano reads the original text in this page. Long documents or a deeper answer need the cloud: you see the exact redacted text first, and nothing is sent unless you click Send.

        
Draft: Gemini Nano writes from the redacted copy (placeholders like [PERSON_1]); the real details are filled back in here, in your browser. The cloud is used only if you review the redacted text and click Send.

        
Requires Chrome 139+ with Gemini Nano enabled for the on-device path (see the repo README for the two flags). Without Nano (or if the on-device check fails or doesn't finish within a few seconds), only the deterministic redaction is applied: names, organizations and addresses are not machine-detected. You can still review that exact redacted copy and send it to the cloud; the consent dialog says plainly that only deterministic redaction was applied, and Send stays blocked if any email, phone number, SSN or card number is still visible.
