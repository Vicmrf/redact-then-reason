      How this works
      
Regex detectors run instantly; then, if Gemini Nano is available, an on-device pass adds names, organizations and addresses. Nothing is sent anywhere.

      
Explain: on-device, Gemini Nano reads the original text in this panel. Long documents or a deeper answer need the cloud: you see the exact redacted text first, and nothing is sent unless you click Send.

      
Draft: Gemini Nano writes from the redacted copy (placeholders like [PERSON_1]); the real details are filled back in here, on this device. The cloud is used only if you review the redacted text and click Send.

      
Capture reads the current tab only when you click it. The text lands in the box above; nothing runs until you click Redact.
